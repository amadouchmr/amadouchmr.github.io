# AMADOU press kit

Everything you normally change is in the **EDIT HERE** block at the top of `index.html`.

| To change | Do this |
|---|---|
| Email, Instagram, tagline, bio | Edit the line in the EDIT HERE block |
| A SoundCloud player | SoundCloud → Share → Embed → paste the code between the backticks |
| Press photos | Drop the .jpg in `press/`, add or remove its line under `photos:` (order = order on the page). Re-zip the photos into `press/AMADOU_Press_Photos.zip` |
| Videos | Drop the .mp4 (under 50 MB) and a cover .jpg in `video/`, add a line under `videos:` |
| Big photo at the top | Replace `img/hero.jpg` |

Name new files like the existing ones, with no spaces: `AMADOU_Press_06_2000x2500.jpg`.

Then in GitHub Desktop: write a short summary → **Commit to main** → **Push origin**. The site updates in about a minute.
